  - title: Workflows & boards
    details: Configurable statuses per project (To Do / In Progress / Done categories) with a visual editor; Scrum and Kanban boards with status-mapped columns, WIP limits and swimlanes.
  - title: Backlog, sprints & reports
    details: Rank the backlog, plan, start and complete sprints. Burndown, velocity, created vs resolved, cumulative flow and control chart.
  - title: JQL search
    details: Jira-style queries over every project you can browse — fields, IN / NOT IN, text match, IS EMPTY, currentUser(), openSprints(), ORDER BY.
  - title: Integrations
    details: Signed outgoing webhooks, GitHub commit and pull-request linking, an OpenAPI 3.1 contract and personal access tokens.
  - title: AI assistants
    details: A built-in Model Context Protocol server. Connect Claude and other MCP clients with a token or with OAuth 2.1 consent.
  - title: Enterprise sign-in
    details: Google, GitHub, any OpenID Connect provider, SAML 2.0 and SCIM 2.0 provisioning.
  - title: Live everywhere
    details: An embedded MQTT broker pushes change hints to browsers (over WebSocket) and to your own integrations.
  - title: Chat & huddles
    details: Slack-style channels and threads, video huddles with screen share, shared whiteboards and docs — all self-hosted.
